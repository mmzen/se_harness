# SE Harness 0.20.0 release preparation

This is the candidate release summary, not a publication announcement.
REL-SEH-031 defines the exact release membership. The repository continues to
use released evaluator 0.19.0 until separately authorized adoption.

## Changes in this candidate

- Instruction guides use current authority references, preserve decision rules
  and explain when an agent can reuse material retained in context.
- New installations omit six obsolete human-guide seeds. Upgrades preserve
  repository-owner content and the supported legacy migration behavior.
- Native instruction-delivery evidence distinguishes actual host events from
  protocol fixtures, package inspection and later public installation.
- Release delivery accounts for the evaluator, marketplace, documentation,
  demonstration and release markers. Evaluator publication alone is incomplete.
- Plugin source inputs select 0.2.2. Its final assembly requires the newly
  published 0.20.0 wheel, followed by separate package qualification and exact
  marketplace publication. Current public delivery remains 0.2.1 / 0.19.0.

## Delivery and adoption

WO-RLS-026 prepares the evaluator and aggregate verification. After human
verification and release decisions, the existing publisher delivers the exact
bound evaluator. WO-PLG-030 then qualifies the plugin and prepares its ordinary
descendant commit on plugin-marketplace. WO-PLG-031 checks public installation
and update on both claimed Windows hosts and updates current claims.

Each stage retains exact identities and observed results. Desktop UI, automatic
threshold compaction and other platforms are not inferred from the Windows CLI
evidence. Latest/last movement needs its own exact authorization.

Repository adoption and deletion of existing owner guide pointers follow later.
This release does not silently change real host profiles or repository owners'
files. Linked revisions and configurable exceptions remain future capabilities.
