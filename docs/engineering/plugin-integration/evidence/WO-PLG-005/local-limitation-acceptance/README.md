permissions. The plugin does not guarantee prevention of every local file
change. The agent must still follow the approved work-order scope; accepting
this limitation does not authorize out-of-scope work.

## Intended acceptance control

checks to prevent unauthorized changes entering protected code. Moving scope
records to a remote service is a future direction, not a currently demonstrated
compensating control. Scope records, the exact candidate and the check result
must be protected from agent changes or bypass before that guarantee is claimed.
