## What is observed

- `debug prompt-input` includes `codex-probe:setup` and its isolated cache path. This proves discovery, not execution of the skill.
- The real app-server `hooks/list` response lists SessionStart and PreToolUse hooks as enabled, plugin-sourced, and **untrusted**, without loading errors. No hook execution was observed.
- A model turn first failed because the outer sandbox blocked sockets. The authorized network retry reached the API and failed with **401, missing authentication**. Network restriction and missing login are separate environment blockers, not Codex incompatibilities.
- `thread/start` succeeds locally. Resuming that empty thread immediately returns “no rollout found.” An empty-thread compact request is accepted, but no completed compaction or fresh context delivery was observed before shutdown. This does not establish normal resume/compaction behavior.

These direct invocations **do not prove host event delivery, hook trust, skill behavior, or automatic governance enforcement**. The original live profile still contains the file-based fixture while its operator login is pending.

## Fixture safety checks

[Ten tests pass](fixture-tests/job-bound-safety-tests.json), including isolated environment inputs, preserved prior evidence, an early-exiting parent whose descendant holds a pipe, and survival of an unrelated process. The suite itself ran inside a 15-second process boundary and finished in 2.50 seconds.

The initial cleanup approach did not bound a descendant-held output pipe; its regression attempt took 63.47 seconds and failed. The revised Windows launcher creates each child suspended, assigns it to a private job, then resumes it. Closing or terminating that job handles its descendants even after the parent exits. This uses [Windows job objects](https://learn.microsoft.com/en-us/windows/win32/procthread/job-objects), without changing host policy. The later actual app-server run reports [zero active job processes and completed output readers](inline-local-host/app-server/capture.json). Original host attempts predate this cleanup fix and are not retroactively attributed its guarantees.
