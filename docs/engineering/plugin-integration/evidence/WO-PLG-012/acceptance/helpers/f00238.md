The boundary's initial subprocess audit comparison assumed an argv list. On
Windows, CPython delivers the rendered command-line string at this audit event.
The already-approved exact read-only Git and packaged validator calls were
therefore blocked. The actual doctor refusal, audit events, and executed worker
source are retained. This is a boundary portability defect, not a product failure.
The correction compares Windows strings only against stdlib list2cmdline output
for the same predeclared exact argv. Canaries and doctor are rerun in new outputs.
