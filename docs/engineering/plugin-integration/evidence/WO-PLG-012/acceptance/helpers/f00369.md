Linux CPython passed cwd as a Path object to the subprocess audit event. The
boundary logger attempted JSON serialization without Path conversion, aborting
before the approved evaluator version child. No denied effect or target change
occurred. This is a boundary logging portability defect; actual traceback and
executed worker source are retained. The correction serializes PathLike objects
with os.fspath. Final Linux cases use new output and a full new calibration.
