# Capability: Adopt a published successor governor through the standard root

## Capability statement

`A repository owner can adopt exact public se-harness 0.6.0 after publication through one plan-first, root-only transaction without making checkout source or a locally rebuilt wheel authoritative.`

## Boundaries

- Applies only to the standard root, managed workflow, lock, exact integration adjustment, contextual truth, and retained upgrade evidence.
- Uses an isolated installation of the immutable public wheel.
- Preserves every product, release, tag, publication, deployment, historical artifact, and external-policy identity.
- Grants no commit, push, PR, merge, VREC, release, publication, deployment, or maintenance authority.

## Candidate requirements

- `REQ-HUP-004`: prove the exact public successor evaluator and publication identity.
- `REQ-HUP-005`: apply only the reviewed schema-2-to-schema-3 standard-root transaction.
- `REQ-HUP-006`: prove complete-graph operation and preserve all non-root state.
