# Operating Contract: Operate work-order lifecycle consistency

## Operational checks

Monitor formal validation for uncovered verified or released work, review lifecycle corrections as accountable governance changes, and keep canonical/root managed files synchronized.

## Escalation

Escalate lifecycle ambiguity, missing evidence, uncovered verified work, or any proposed automated authority transition to the repository and quality owners.
