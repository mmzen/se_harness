# Root Cause Analysis Engineering Domain

> Repository-owned index. Formal artifact authority comes from TOML metadata, typed relations, and lifecycle state—not this directory or index.

This domain governs publication of a factual, non-authoritative root cause analysis for the 0.5.0 release-governance deadlock. The RCA itself belongs under `docs/rca/`; it records incident learning but does not approve work, verify a candidate, release software, or retroactively authorize the emergency recovery.
