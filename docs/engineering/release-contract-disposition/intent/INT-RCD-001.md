# Intent: Dispose obsolete draft release proposals

Six per-feature release contracts remain in `draft` even though their gated work was subsequently released under authoritative aggregate contracts. The retained drafts create recurring definition work without representing a live release proposal.

The repository needs an explicit, reviewable disposition that preserves the abandoned proposals and their original scope while making the actual release lineage unambiguous.
