# Native delivery qualification and adoption

The reviewed **Verity Plane 0.2.0** plugin is adopted in the real Codex and Claude
user profiles. Both profiles passed native startup and compaction delivery on
this repository with the exact commands recorded in the evidence. The repository
evaluator remains **0.19.0**. No public plugin release or repository harness
upgrade occurred.

Claude required session-only `--model opus` because its saved model was unavailable.
That setting remains unchanged; default-model usability is not part of the pass.
Codex's exact reviewed hook is trusted through its native control.

workspace directory and must remain available. Unrelated plugins and marketplace
