# Compact injected entry

## Why

Agents need the rules that apply throughout the task without loading the complete procedure collection.

## Behavior

The entry retains the RFC language, Goals, the agreed nine named invariants, scope of applicability, a brief Human/Agent authority boundary, command convention, transient-material convention, and reading router. Full procedures and model tables are reached by condition.

## Acceptance

Inspect the retained review source and destination map: every always-applicable rule has an entry destination. Record the entry word count against the 1,000–1,300-word writing target. Explain any necessary excess; the target is not a gate or permission to omit rules.

## Failure

A missing, wrong-repository or incompatible entry prevents a claim that the harness context is ready. Report the exact missing input.
