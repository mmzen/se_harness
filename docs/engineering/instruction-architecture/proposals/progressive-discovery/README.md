# Progressive instruction discovery proposal

These files preserve the reviewed design inputs used to draft the linked formal
package. They are durable proposal provenance, not transient agent notes,
installed instructions, accepted definitions, or passing verification evidence.
The instruction source still contains review issues identified in the formal
specification. Its 0.18.0 header must not be used as an availability claim.

Read the new specification for the proposed binding scope. The source hashes
are recorded in sources.json. Future implementation retains a rule disposition
map rather than silently editing these snapshots.
