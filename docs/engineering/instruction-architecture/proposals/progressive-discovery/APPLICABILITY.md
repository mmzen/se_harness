1. Select an exact released candidate with verified coverage of these three WOs.

3. Preview the upgrade using that released evaluator; inspect every ownership

   startup/compaction behavior. Preserve the prior release's historical records.

selected here. Unsupported exception and linked-definition-revision capabilities
remain outside these work orders.
