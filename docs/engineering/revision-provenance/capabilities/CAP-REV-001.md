# Capability

An assurance or release owner can identify the exact clean Git commit verified for an approved work order, prepare a release record bound to that same commit, and traverse from the record back to the governing requirements and intent.

The capability prepares reviewable records. It does not approve verification, authorize release, create tags, commit files, or publish artifacts.
