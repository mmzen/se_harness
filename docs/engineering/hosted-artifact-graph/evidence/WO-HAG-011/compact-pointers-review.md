# Compact pointers and saved-content review

This remains within WO-HAG-011's approved client and instruction scope. It changes
no accepted criterion, source fixture, model, permission or service contract.

Candidate25 exposed two problems. Catalogue pointers repeated long absolute paths
and could exceed small catalogue values. The second positive Claude trial also
claimed complete verification content while one stated condition had no planned
check. Its saved draft, failure and exact readbacks are retained in
[the candidate25 assessment](concise-results-assessment.md).

The view now gives its response path once in `full_response`. Catalogue omissions
name a JSON pointer into that file. A catalogue value remains inline when the
pointer and omission marker would be larger. This retains the same selected
instructions, findings and raw bytes without adding an option or result schema.
Other omission types preserve their existing locations and required-read flags.

The guide makes the existing review rule executable: identify the planned check
for every pass condition, add a missing check or narrow the claim, and apply this
review to the saved document before claiming completeness. It supplies no case
answer and no new acceptance obligation. This replaces an abstract sentence;
it adds no separate review file, gate or mandatory tool call.

Client regression and real installed-client checks cover the new presentation.
Fresh native cases assess the candidate under the unchanged contract. Earlier
trials are not combined into its repetition set. Service qualification reuse is
limited to unchanged server, dependencies and released evaluator bytes.
