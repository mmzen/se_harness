# Public delivery evidence for 0.23.0 / plugin 0.2.7

Use [RLS-SEH-034](../../releases/RLS-SEH-034.md) for the release decision and
[VREC-SEH-034](../../verification-records/VREC-SEH-034.md) for candidate verification.
The [assessment](../WO-RLS-045/verification-assessment-48e851bb.md) preserves
R23-NATIVE-010/011 as open and Codex Windows desktop as unverified under
DEC-RLS-010/011. These limits do not waive required public CLI checks.

Candidate qualification and release authority do not prove public availability.
Only observed receipts for the frozen plan establish delivery. This directory
retains `observations.json` and `delivery-result.json` when those operations run.
An absent, pending or failed receipt does not establish success.

Required observations cover the public evaluator install, both CLI fresh and
0.2.6-to-0.2.7 update routes, marketplace identity, current documentation, Pages,
maintenance line and latest/last readback. Compare installed bytes with the
[public package identity](https://github.com/mmzen/se_harness/blob/plugin-marketplace/PACKAGE-IDENTITY.json).

[WO-RLS-047](../../work-orders/WO-RLS-047.md) owns delivery and its later
commit-bound assurance under [VER-RLS-041](../../verification/VER-RLS-041.md).
The service remains a private source build. Git remains authoritative.
Repository adoption and updates to the user's host are separate operations.
