# Capability

A repository owner can initialize or adopt the complete standard harness, validate its artifact graph, generate its evidence explorer, diagnose installation drift, and safely plan or apply tool-owned upgrades.

The capability does not approve target-repository intent, rewrite customized files, publish a package, or authorize a release.
